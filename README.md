# atividade01-php-poo

Objetivo 



Desenvolver uma página PHP que apresente informações sobre uma planta, utilizando os conceitos de classes, objetos, propriedades, métodos, visibilidade, encapsulamento e construtor. 



O HTML e o CSS já estão prontos (pegue em anexo aqui nesta mensagem o index e o estilos).  



Atenção! crie também um novo repositório chamado atividade01-php-poo. 



Sua tarefa é implementar o PHP necessário para fazer a página funcionar. 

 

Parte 1: Implementação da classe 

Crie uma pasta chamada src e dentro dela crie uma classe chamada Planta com as seguintes características: 

Declare três propriedades privadas: 
$nome 
$especie 
$aguaPorDia 
Crie um método construtor que receba três parâmetros e utilize esses valores para inicializar as propriedades do objeto. 
Crie os seguintes métodos públicos: 
getNome(): retorna o nome popular da planta. 
getEspecie(): retorna a espécie da planta. 
getAguaPorDia(): retorna a quantidade diária de água. 
calcularAguaSemanal(): retorna a quantidade de água recomendada para sete dias. 
Dica: para calcular a quantidade semanal, multiplique a quantidade diária por 7. 

 

Parte 2: Criação do objeto 

Depois da declaração da classe: 

Crie um objeto da classe Planta. 
Utilize os seguintes dados: 

Informação 

Valor 

Nome popular 

Suculenta 

Espécie 

Echeveria elegans 

Água por dia 

15 ml 


Utilize os métodos do objeto para apresentar as informações na página. 
 

Parte 3: Exibição das informações 

Localize os pontos indicados pelos comentários TODO no código. 

Utilize os métodos do objeto para preencher os seguintes elementos HTML: 

Nome popular da planta. 
Nome científico. 
Quantidade diária de água. 
Quantidade de água recomendada para sete dias. 
Não altere o HTML nem o CSS. 



 

Sua atividade deve atender os seguintes critérios: 

A classe possui as três propriedades privadas. 
O construtor inicializa corretamente as propriedades. 
Os métodos retornam os valores esperados. 
O objeto é criado com os dados solicitados. 
A página exibe corretamente todas as informações. 
O encapsulamento é respeitado: as propriedades são acessadas por meio dos métodos públicos. 
 

Atenção: não é necessário criar formulários, utilizar banco de dados ou implementar outras funcionalidades.
